# Release QA Interview Prep

A self-test question bank for a mid-level release QA interview.

## Files

| File | Contents |
|---|---|
| `qa-100.md` | 100 open questions with hidden answers |
| `mcq-150.md` | 150 multiple-choice questions with hidden answers and explanations |

## How to use

1. Read a question and answer it aloud or in writing.
2. Click **Show answer** to compare. The answer is hidden so you cannot read it by accident.
3. For an MCQ, choose A–D before revealing, and read the explanation even when you are right.

| Part | Q&A | MCQs | Topics |
