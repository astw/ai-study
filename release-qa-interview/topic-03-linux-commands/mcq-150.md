## Part 1 — Orientation and System Information (12 questions)

### Directory and user basics

#### MCQ 1. A release script calls `pwd` before packaging. What does the command print?

A. The user name
B. The current working directory
C. The host name
D. The last command

<details>
<summary>Show answer</summary>

**Correct answer: B.** `pwd` prints the current working directory, which is where relative paths will resolve.

</details>

#### MCQ 2. A tester is three directories deep and runs `cd ..`. Where do they end up?

A. Goes to the home directory
B. Goes to the previous directory
C. Goes up one directory
D. Lists the parent directory

<details>
<summary>Show answer</summary>

**Correct answer: C.** `..` means the parent directory, so `cd ..` moves up one level.

</details>

#### MCQ 3. A tester moves into `releases/` and then runs `cd -`. Where do they go?

A. Returns to the previous directory
B. Goes to the root directory
C. Goes to the home directory
D. Deletes the current directory

<details>
<summary>Show answer</summary>

**Correct answer: A.** `cd -` switches back to the directory you came from, like a toggle.

</details>

#### MCQ 4. A tester needs to see `.env` while listing a directory. Which `ls` flag includes hidden dotfiles?

A. `-l`
B. `-h`
C. `-t`
D. `-a`

<details>
<summary>Show answer</summary>

**Correct answer: D.** `-a` includes entries whose names start with a dot, such as `.env` and `.gitignore`.

</details>

#### MCQ 5. A directory listing shows sizes like `1.2K`. Which `ls` flag produced that?

A. Shows hidden files
B. Prints human-readable sizes
C. Sorts by time
D. Shows only directories

<details>
<summary>Show answer</summary>

**Correct answer: B.** `-h` prints sizes such as `1.2K` or `3.4M`, which is easier to scan than raw bytes.

</details>

#### MCQ 6. A tester runs `sudo whoami` to check a service account. What does it print?

A. `root`
B. The original login user
C. The host name
D. Nothing

<details>
<summary>Show answer</summary>

**Correct answer: A.** `sudo` changes the effective user to root, so `whoami` prints `root`. Use `id` or `logname` for the original account.

</details>

#### MCQ 7. A permission problem depends on the tester's group memberships. Which `id` flag prints all group IDs?

A. The user ID
B. The primary group ID
C. All group IDs
D. The home directory

<details>
<summary>Show answer</summary>

**Correct answer: C.** `-G` prints every group ID the user belongs to; `-g` prints only the primary group.

</details>

### System information

#### MCQ 8. A bug report needs the kernel release. Which `uname` flag prints it?

A. The host name
B. The CPU count
C. The distribution name
D. The kernel release

<details>
<summary>Show answer</summary>

**Correct answer: D.** `-r` prints the kernel release. It does not identify the Linux distribution.

</details>

#### MCQ 9. A tester needs the host's fully qualified name for a certificate check. Which `hostname` flag tries to print it?

A. The fully qualified domain name
B. The kernel version
C. The IP address
D. The current user

<details>
<summary>Show answer</summary>

**Correct answer: A.** `-f` asks for the fully qualified domain name; the result depends on the host's DNS and configuration.

</details>

#### MCQ 10. A build is about to download a large artifact. Which command shows free space on the mounted filesystems?

A. `du -sh`
B. `df -h`
C. `free -h`
D. `ls -lh`

<details>
<summary>Show answer</summary>

**Correct answer: B.** `df -h` reports filesystem capacity and free space. `du` reports directory usage instead.

</details>

#### MCQ 11. A tester on macOS needs the memory summary that `free -h` gives on Linux. Which command should they use?

A. `df -h`
B. `du -sh`
C. `top -h`
D. `vm_stat`

<details>
<summary>Show answer</summary>

**Correct answer: D.** macOS does not ship `free`; use `vm_stat` and `top` for memory information.

</details>

#### MCQ 12. A tester needs one snapshot of running processes for a bug report. Which command should they use?

A. `top`
B. `htop`
C. `ps`
D. `uptime`

<details>
<summary>Show answer</summary>

**Correct answer: C.** `ps` prints a snapshot; `top` and `htop` update continuously.

</details>

## Part 2 — Files and Folders (18 questions)

### Creating and copying

#### MCQ 13. A release script must create `releases/2026-11-18/logs` even when `releases` does not exist. Which `mkdir` flag does the job?

A. Fails if `releases` exists
B. Creates missing parents and the final directory
C. Creates only the last directory
D. Removes the directory

<details>
<summary>Show answer</summary>

**Correct answer: B.** `-p` creates every missing parent and does not fail when the final directory already exists.

</details>

#### MCQ 14. A script runs `touch -c app.log` when `app.log` is missing. What happens?

A. Does not create it
B. Creates an empty file
C. Deletes it
D. Renames it

<details>
<summary>Show answer</summary>

**Correct answer: A.** `-c` suppresses creation, so the command only updates an existing file's timestamps.

</details>

#### MCQ 15. A tester needs to copy a whole build directory to an artifact folder. Which `cp` flag does it recursively?

A. `-p`
B. `-v`
C. `-r`
D. `-f`

<details>
<summary>Show answer</summary>

**Correct answer: C.** `-r` recurses into directories. `-p` preserves metadata, and `-v` prints each file.

</details>

#### MCQ 16. A tester copies a build and must keep its timestamps and mode. Which `cp` flag preserves them?

A. Only the filename
B. Only the directory structure
C. The file's content hash
D. Mode, ownership, and timestamps

<details>
<summary>Show answer</summary>

**Correct answer: D.** `-p` preserves the mode, ownership, and timestamps of the copied files.

</details>

#### MCQ 17. A tester runs `mv app.zip artifacts/` and a file with that name is already there. What happens by default?

A. Refuses to move
B. Overwrites it
C. Appends to it
D. Creates a backup

<details>
<summary>Show answer</summary>

**Correct answer: B.** `mv` overwrites an existing destination unless you use `-i` or the destination is a directory.

</details>

#### MCQ 18. A tester is about to run `rm -rf` on a build directory. Why is that risky?

A. It removes recursively and forces deletions with no undo
B. It only removes empty directories
C. It moves files to the trash
D. It asks for confirmation

<details>
<summary>Show answer</summary>

**Correct answer: A.** It recurses and forces the removal, with no trash or undo. A typo or empty variable can delete far more than intended.

</details>

### Links, search, and metadata

#### MCQ 19. A release process needs a stable `current` path that points at a dated build. Which command creates that link?

A. A hard link
B. A copy of `target`
C. A directory
D. A symbolic link

<details>
<summary>Show answer</summary>

**Correct answer: D.** `-s` creates a symbolic link, a small file that points at another path.

</details>

#### MCQ 20. A tester is comparing a hard link with a symlink. Which statement about a hard link is true?

A. It can cross filesystems
B. It points to a path
C. It is another directory entry for the same file data
D. It is always a symlink

<details>
<summary>Show answer</summary>

**Correct answer: C.** A hard link shares the same inode and file data; it cannot cross filesystems and does not point to a path.

</details>

#### MCQ 21. A tester needs to find every zip file under `releases`. Which command does it?

A. `find releases -type f -name '*.zip'`
B. `grep -r '*.zip' releases`
C. `ls releases *.zip`
D. `file releases '*.zip'`

<details>
<summary>Show answer</summary>

**Correct answer: A.** `find` with `-name '*.zip'` and `-type f` matches regular files by name. Quote the pattern so the shell does not expand it first.

</details>

#### MCQ 22. A tester wants only regular files from `find`. Which filter does that?

A. `-name`
B. `-type f`
C. `-size`
D. `-mtime`

<details>
<summary>Show answer</summary>

**Correct answer: B.** `-type f` keeps regular files; `d` is for directories, and `l` is for symlinks.

</details>

#### MCQ 23. A tester suspects a build contains files over 100 MB. Which `find` command checks it?

A. Files smaller than 100 MB
B. Directories larger than 100 MB
C. Files modified in the last 100 minutes
D. Files larger than 100 MB

<details>
<summary>Show answer</summary>

**Correct answer: D.** `+100M` means greater than 100 mebibytes; `-type f` keeps regular files.

</details>

#### MCQ 24. A tester wants the logs modified in the last day. Which `find` command shows them?

A. Files older than one day
B. Files exactly one day old
C. Files modified in the last day
D. Files larger than one MB

<details>
<summary>Show answer</summary>

**Correct answer: C.** `-mtime -1` means less than one day old, so it finds files modified within the last day.

</details>

#### MCQ 25. A tester needs a custom `stat` format on Linux. Which flag is Linux-specific?

A. `-c`
B. `-f`
C. `-l`
D. `-s`

<details>
<summary>Show answer</summary>

**Correct answer: A.** GNU `stat` uses `-c`; macOS and BSD use `-f`. The two formats are not interchangeable.

</details>

#### MCQ 26. A tester receives `artifact.zip` and needs to confirm its content type. Which command should they use?

A. The owner and permissions
B. The content type
C. The download URL
D. The checksum

<details>
<summary>Show answer</summary>

**Correct answer: B.** `file` reads the content and reports the type, such as a Zip archive or an ELF binary.

</details>

### Paths and globs

#### MCQ 27. A tester is reading a build script and needs an absolute path. Which example is absolute?

A. `artifacts/app.zip`
B. `./logs/app.log`
C. `/var/log/myapp/app.log`
D. `~/logs/app.log`

<details>
<summary>Show answer</summary>

**Correct answer: C.** An absolute path starts at `/`. `~` is a shell expansion for the home directory, not a literal absolute root.

</details>

#### MCQ 28. A tester writes `~/logs/app.log` in a command. What does `~` expand to?

A. The root directory
B. The current directory
C. The parent directory
D. The home directory

<details>
<summary>Show answer</summary>

**Correct answer: D.** The shell expands `~` to your home directory; `.` is the current directory and `..` is the parent.

</details>

#### MCQ 29. A tester runs `ls *.log` in a log directory. What does the glob match?

A. Names ending in `.log`
B. Names starting with `.log`
C. Names containing `log`
D. Only `app.log`

<details>
<summary>Show answer</summary>

**Correct answer: A.** `*` matches any characters, so `*.log` matches names ending in `.log` in the current directory.

</details>

#### MCQ 30. A tester needs to pass `artifacts/my build.zip` to a command. How should the path be written?

A. Split it into two arguments
B. Quote it, for example `"artifacts/my build.zip"`
C. Prefix it with `$`
D. Use `find` only

<details>
<summary>Show answer</summary>

**Correct answer: B.** Quoting keeps the spaces inside one argument; otherwise the shell splits the path into separate words.

</details>

## Part 3 — Viewing and Searching Text and Logs (20 questions)

### Viewing files

#### MCQ 31. A log is 2 GB and a tester needs to search it. Why use `less` instead of `cat`?

A. It edits the file
B. It compresses the file
C. It changes permissions
D. It lets you scroll and search without flooding the terminal

<details>
<summary>Show answer</summary>

**Correct answer: D.** `less` is a pager: you can scroll, search, and quit without printing the entire file.

</details>

#### MCQ 32. A tester opens a large log in `less` and needs to find `timeout`. What should they type?

A. `q`
B. `G`
C. `/pattern`
D. `:w`

<details>
<summary>Show answer</summary>

**Correct answer: C.** Type `/pattern` and press Enter; `n` moves to the next match.

</details>

#### MCQ 33. A tester is inside `less` and wants to return to the shell. What key quits?

A. `q`
B. `Esc`
C. `Ctrl-C`
D. `:q!`

<details>
<summary>Show answer</summary>

**Correct answer: A.** `q` exits the pager. `:q!` is a vi command, not a `less` command.

</details>

#### MCQ 34. A tester needs the first 20 lines of a CSV header. Which command shows them?

A. The last 20 lines
B. Every 20th line
C. The first 20 bytes
D. The first 20 lines

<details>
<summary>Show answer</summary>

**Correct answer: D.** `head` prints from the start, and `-n 20` limits it to 20 lines.

</details>

#### MCQ 35. A tester needs the last 100 lines of a log for a bug report. Which command shows them?

A. The first 100 lines
B. The last 100 lines
C. The lines containing `100`
D. The 100th line

<details>
<summary>Show answer</summary>

**Correct answer: B.** `tail` prints from the end, which is why it is the default tool for recent log entries.

</details>

#### MCQ 36. A test log rotates during a long run. Which `tail` flag keeps following it?

A. It prints more lines
B. It compresses the output
C. It follows the file name across rotation
D. It follows only stderr

<details>
<summary>Show answer</summary>

**Correct answer: C.** `-F` reopens the file after rotation, while `-f` can stop when the original file is replaced.

</details>

### Searching and filtering

#### MCQ 37. A tester searches a log for `error` and also wants `Error` and `ERROR`. Which `grep` flag does that?

A. Finds error case-insensitively
B. Inverts the match
C. Counts matches
D. Searches recursively

<details>
<summary>Show answer</summary>

**Correct answer: A.** `-i` ignores case, so it matches `error`, `Error`, and `ERROR`.

</details>

#### MCQ 38. A tester finds a match and needs its line number for the report. Which `grep` flag adds it?

A. Case insensitivity
B. Line numbers
C. Recursion
D. Inversion

<details>
<summary>Show answer</summary>

**Correct answer: B.** `-n` prefixes each matching line with its line number, which helps when you open the file later.

</details>

#### MCQ 39. A tester needs to search every file under `/var/log/myapp`. Which `grep` flag recurses?

A. Reads from standard input
B. Counts matches
C. Searches the directory recursively
D. Reverses the output

<details>
<summary>Show answer</summary>

**Correct answer: C.** `-r` recurses through the directory and searches each file.

</details>

#### MCQ 40. A tester wants to hide health-check lines while searching a log. Which `grep` flag inverts the match?

A. Shows only health lines
B. Counts health lines
C. Searches health recursively
D. Shows lines that do not match `health`

<details>
<summary>Show answer</summary>

**Correct answer: D.** `-v` inverts the match, so it removes the health-check noise.

</details>

#### MCQ 41. A script runs `grep error app.log` and finds nothing. What exit status should it expect?

A. 1
B. 0
C. 2
D. 255

<details>
<summary>Show answer</summary>

**Correct answer: A.** `0` means a match, `1` means no match, and `2` means an error. A script must distinguish 1 from 2.

</details>

### Text processing

#### MCQ 42. A tester needs the number of lines in `app.log`. Which command and flag?

A. Words
B. Bytes
C. Newline characters
D. Files

<details>
<summary>Show answer</summary>

**Correct answer: C.** `-l` counts newline characters, so a final line without a newline is not counted.

</details>

#### MCQ 43. A CSV report has the status in the second comma-separated field. Which `cut` command prints it?

A. The second character
B. The second comma-separated field
C. The first two fields
D. Every field after the comma

<details>
<summary>Show answer</summary>

**Correct answer: B.** `-d','` sets the delimiter and `-f2` selects the second field.

#### MCQ 44. A file contains counts `10` and `2`, and a tester needs numeric order. Which `sort` flag should they use?

A. It sorts case-insensitively
B. It removes duplicates
C. It sorts by month
D. It compares numbers rather than text

<details>
<summary>Show answer</summary>

**Correct answer: D.** Plain `sort` is lexicographic, so `10` comes before `2`; `-n` compares numeric values.

</details>

#### MCQ 45. A tester pipes a log into `uniq -c` and sees duplicate counts. Why must the input be sorted first?

A. `uniq` only collapses adjacent duplicates
B. `uniq` only works on numbers
C. `uniq` sorts automatically
D. `uniq` requires a file argument

<details>
<summary>Show answer</summary>

**Correct answer: A.** `uniq` compares neighboring lines, so duplicate lines that are not adjacent survive.

</details>

#### MCQ 46. A tester runs `sort app.log | uniq -c`. What does the output show?

A. Only unique lines
B. Each unique line with its count
C. The last duplicate
D. The file size

<details>
<summary>Show answer</summary>

**Correct answer: B.** `-c` prefixes each distinct line with the number of times it appeared after sorting.

</details>

#### MCQ 47. A tester wants to watch a test run and also save it to `artifacts/test.log`. Which command does both?

A. Deletes the log
B. Reads the log
C. Compresses the log
D. Writes output to the terminal and the file

<details>
<summary>Show answer</summary>

**Correct answer: D.** `tee` splits the stream: you keep watching it while the file keeps a copy.

</details>

#### MCQ 48. A release incident needs the most common error lines in the last 1,000 lines. Which pipeline shows them?

A. `head -n 1000 app.log | grep error`

<details>
<summary>Show answer</summary>

**Correct answer: C.** It limits to the recent window, filters errors, groups and counts them, ranks the counts, and shows the top 20.

</details>

#### MCQ 49. What does `cut -d` set?

A. The delimiter
B. The output file
C. The number of fields
D. The sort order

<details>
<summary>Show answer</summary>

**Correct answer: A.** `-d` sets the field delimiter, and `-f` selects the fields to print.

</details>

#### MCQ 50. What does `grep` exit 2 mean?

A. A match was found
B. An error occurred, such as a bad pattern or unreadable file
C. No match was found
D. The file is empty

<details>
<summary>Show answer</summary>

**Correct answer: B.** Exit 1 means no match; exit 2 means `grep` itself hit an error. Treating both as "no match" hides a real problem.

</details>

## Part 4 — Processes and Services (18 questions)

### Process inspection

#### MCQ 51. Which `ps` column is the parent process ID?

B. `PID`
C. `STAT`
D. `TTY`

<details>
<summary>Show answer</summary>

**Correct answer: A.** `PPID` is the parent process ID; `PID` is the process itself.

</details>

#### MCQ 52. Which `ps` style shows the PPID prominently?

A. `ps aux`
B. `ps -ef`
C. `ps -l`
D. `top`

<details>
<summary>Show answer</summary>

**Correct answer: B.** `ps -ef` is System V style and includes PPID in its default columns.

</details>

#### MCQ 53. What does the `Z` state in `ps` mean?

A. Running
B. Sleeping
C. Zombie
D. Stopped

<details>
<summary>Show answer</summary>

**Correct answer: C.** `Z` is a zombie: the process has exited but its parent has not reaped it.

</details>

### Signals and jobs

#### MCQ 54. A tester runs `kill 1234` without a signal flag. Which signal is sent?

A. `KILL`
B. `HUP`
C. `INT`
D. `TERM`

<details>
<summary>Show answer</summary>

**Correct answer: D.** `kill PID` sends `TERM` by default, asking the process to stop cleanly.

</details>

#### MCQ 55. Which signal cannot be caught and forces termination?

A. `KILL`
B. `TERM`
C. `HUP`
D. `INT`

<details>
<summary>Show answer</summary>

**Correct answer: A.** `KILL` is handled by the kernel and cannot be caught, so the process cannot clean up.

</details>

#### MCQ 56. Which key suspends the current job?

A. `Ctrl-C`
B. `Ctrl-Z`
C. `Ctrl-D`
D. `Ctrl-L`

<details>
<summary>Show answer</summary>

**Correct answer: B.** `Ctrl-Z` suspends the job; `bg` continues it in the background and `fg` brings it back.

</details>

#### MCQ 57. What does `bg %1` do?

A. Kills job 1
B. Brings job 1 to the foreground
C. Continues job 1 in the background
D. Lists job 1

<details>
<summary>Show answer</summary>

**Correct answer: C.** `bg` resumes a suspended job in the background.

</details>

#### MCQ 58. What does `fg %1` do?

A. Continues job 1 in the background
B. Kills job 1
C. Lists job 1
D. Brings job 1 to the foreground

<details>
<summary>Show answer</summary>

**Correct answer: D.** `fg` brings the job back to the terminal so you can interact with it.

</details>

#### MCQ 59. A tester needs the PIDs of background test jobs. Which `jobs` flag adds them?

A. PIDs
B. Exit codes
C. Environment variables
D. Timestamps

<details>
<summary>Show answer</summary>

**Correct answer: A.** `-l` adds the process IDs, so you can use `ps` or `kill` on the job directly.

</details>

#### MCQ 65. Which `journalctl` flag limits output to errors?

<details>

#### MCQ 66. What is the macOS service manager?

<details>
<summary>Show answer</summary>

</details>

#### MCQ 67. Which command shows the main PID of a service unit?

D. `curl`

<details>
<summary>Show answer</summary>

</details>

#### MCQ 68. A service is active but the port is not listening. What should you check next?

A. DNS
B. The service's bind address and `ss -tulpn`

D. The checksum

<details>
<summary>Show answer</summary>

</details>

## Part 5 — Permissions and Ownership (15 questions)

### Reading permissions

#### MCQ 69. What does the first character `d` in `ls -l` mean?

A. File
B. Symlink
C. Directory
D. Socket

<details>
<summary>Show answer</summary>

**Correct answer: C.** `d` is a directory; `-` is a regular file and `l` is a symlink.
