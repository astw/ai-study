## Part 1 — Networking Fundamentals and Models (20 questions)

### Network types and components

#### MCQ 1. Which statement best describes a node on a network?

A. A cable that carries data
B. A device connected to the network
C. A packet header
D. A DNS record

<details>
<summary>Show answer</summary>

**Correct answer: B.** A node is any device connected to the network, such as a computer, phone, switch, or printer. A link is the connection between nodes, and a packet is a unit of data.

</details>

#### MCQ 2. Which network type covers a single building or campus?

A. PAN
B. MAN
C. LAN
D. WAN

<details>
<summary>Show answer</summary>

**Correct answer: C.** A LAN covers one building or campus; a PAN is personal, a MAN covers a city, and a WAN spans countries or the globe.

</details>

#### MCQ 3. What is the main difference between the internet and an intranet?

A. The internet is public; an intranet is private to an organization.
B. The internet uses IP; an intranet uses only Ethernet.
C. An intranet has no DNS.
D. The internet has no routers.

<details>
<summary>Show answer</summary>

**Correct answer: A.** An intranet is a private network inside an organization and may use the same protocols as the internet. The other options are false limitations.

</details>

#### MCQ 4. Why is data split into packets?

A. To make every packet identical in size
B. To avoid using IP addresses
C. To guarantee delivery without TCP
D. To let many devices share a link and let routers forward traffic independently

<details>
<summary>Show answer</summary>

**Correct answer: D.** Packet switching lets many conversations share a link and lets routers forward each packet independently. It does not guarantee delivery; that is TCP's job.

</details>

### Client-server vs peer-to-peer

#### MCQ 5. A web application uses a central server that all clients call. Which model is this?

A. Peer-to-peer
B. Client-server
C. Full mesh
D. Broadcast

<details>
<summary>Show answer</summary>

**Correct answer: B.** Clients request a service from a central server, which is the client-server model. Full mesh is a topology, and broadcast is an addressing mode.

</details>

#### MCQ 6. What is a key disadvantage of peer-to-peer compared with client-server?

A. Harder to control and secure because there is no central server
B. It cannot share files
C. It requires a public IP for every packet
D. It cannot work on a LAN

<details>
<summary>Show answer</summary>

**Correct answer: A.** Without a central server, peers are harder to inventory, control, and secure. Peer-to-peer can share files and run on a LAN, so the other options are false.

</details>

### OSI and TCP/IP models

#### MCQ 7. Which OSI layer is responsible for logical addressing and routing?

A. Data Link
B. Transport
C. Network
D. Application

<details>
<summary>Show answer</summary>

**Correct answer: C.** The network layer handles logical addressing and routing; IP is the main example. The data link layer handles local frames, and transport handles end-to-end delivery.

</details>

#### MCQ 8. Which OSI layer is closest to the physical cable or radio?

A. Application
B. Transport
C. Data Link
D. Physical

<details>
<summary>Show answer</summary>

**Correct answer: D.** The physical layer carries bits on a wire or through the air. The data link layer is just above it and organizes those bits into frames.

</details>

#### MCQ 9. Which TCP/IP layer combines OSI layers 5 through 7?

A. Application
B. Transport
C. Internet
D. Link

<details>
<summary>Show answer</summary>

**Correct answer: A.** The TCP/IP application layer covers OSI session, presentation, and application. Transport maps to OSI layer 4, Internet to layer 3, and Link to layers 1–2.

</details>

#### MCQ 10. At which TCP/IP layer does TCP operate?

A. Application
B. Transport
C. Internet
D. Link

<details>
<summary>Show answer</summary>

**Correct answer: B.** TCP is a transport-layer protocol. IP is the internet layer, and HTTP is the application layer.

</details>

#### MCQ 11. At which TCP/IP layer does IP operate?

A. Application
B. Transport
C. Link
D. Internet

<details>
<summary>Show answer</summary>

**Correct answer: D.** IP is the internet-layer protocol that provides logical addressing and routing between networks.

</details>

#### MCQ 12. Which OSI layer handles frames and MAC addresses on a local link?

A. Network
B. Transport
C. Data Link
D. Physical

<details>
<summary>Show answer</summary>

**Correct answer: C.** The data link layer builds frames and uses MAC addresses for local delivery. The network layer handles IP addresses instead.

</details>

#### MCQ 13. Why do layered models help troubleshooting?

A. They guarantee that every layer uses the same protocol.
B. They give a shared vocabulary for locating a fault at a specific layer.
C. They remove the need for commands.
D. They make all networks use the same hardware.

<details>
<summary>Show answer</summary>

**Correct answer: B.** Layers let a team say "this looks like DNS" or "this looks like a link problem" and choose the right tool. They do not guarantee protocols or remove the need for evidence.

</details>

#### MCQ 14. Which pair correctly matches a protocol with its layer?

A. HTTP — application; TCP — transport
B. HTTP — transport; IP — application
C. TCP — network; Ethernet — transport
D. DNS — link; ARP — application

<details>
<summary>Show answer</summary>

**Correct answer: A.** HTTP is an application protocol and TCP is a transport protocol. The other pairs swap or misplace the layers.

</details>

### Encapsulation

#### MCQ 15. What is encapsulation?

A. Removing headers as data moves up the stack
B. Encrypting every packet at the application layer
C. Splitting a network into VLANs
D. Adding a header at each layer as data moves down the stack

<details>
<summary>Show answer</summary>

**Correct answer: D.** Encapsulation adds a header at each layer on the way down; decapsulation removes them on the way up. Encryption and VLANs are separate concepts.

</details>

#### MCQ 16. What is the PDU at the transport layer for TCP?

A. Frame
B. Packet
C. Segment
D. Bit

<details>
<summary>Show answer</summary>

**Correct answer: C.** TCP's transport-layer PDU is a segment. A packet is the network-layer PDU, a frame is the link-layer PDU, and bits are physical.

</details>

#### MCQ 17. A frame is the PDU at which layer?

A. Data Link
B. Transport
C. Network
D. Application

<details>
<summary>Show answer</summary>

**Correct answer: A.** The data link layer builds frames. Transport uses segments or datagrams, and the network layer uses packets.

</details>

### Bandwidth, latency, and throughput

#### MCQ 18. What is the difference between bandwidth and throughput?

A. Bandwidth is measured in milliseconds; throughput in packets.
B. Bandwidth is capacity; throughput is the actual rate achieved.
C. Throughput is always greater than bandwidth.
D. They are the same measurement.

<details>
<summary>Show answer</summary>

**Correct answer: B.** Bandwidth is the link's maximum capacity; throughput is what is actually achieved. Throughput is always at most bandwidth.

</details>

#### MCQ 19. Which condition is jitter?

A. A cable is unplugged.
B. A DNS record expires.
C. A port is filtered.
D. The delay between packets varies over time.

<details>
<summary>Show answer</summary>

**Correct answer: D.** Jitter is variation in latency, which is especially harmful to voice and video. The other options are different failure modes.

</details>

#### MCQ 20. A 1 Gbps link has 200 ms RTT and feels slow for interactive use. What does this show?

A. Bandwidth is zero.
B. Throughput cannot be measured.
C. High bandwidth does not remove the effect of latency.
D. The link is half-duplex.

<details>
<summary>Show answer</summary>

**Correct answer: C.** Capacity and delay are different properties; a fast link with high latency still feels slow for interactive traffic. Bandwidth is not zero, and throughput can still be measured.

</details>

## Part 2 — Topologies and Devices (25 questions)

### Topologies

#### MCQ 21. Which topology connects every device to one central switch?

A. Bus
B. Star
C. Ring
D. Full mesh

<details>
<summary>Show answer</summary>

**Correct answer: B.** In a star, every device has its own link to a central switch or hub. The central device is a single point of failure.

</details>

#### MCQ 22. Which topology has the most redundancy but the highest link cost?

A. Bus
B. Star
C. Ring
D. Full mesh

<details>
<summary>Show answer</summary>

**Correct answer: D.** A full mesh connects every node to every other node, giving maximum redundancy at the cost of n(n−1)/2 links.

</details>

#### MCQ 23. Which topology uses one shared backbone?

A. Bus
B. Star
C. Tree
D. Mesh

<details>
<summary>Show answer</summary>

**Correct answer: A.** A bus uses a single backbone that every node taps into. A break or heavy collisions can take down the segment.

</details>

#### MCQ 24. In a ring topology, what does a dual ring provide?

A. Higher bandwidth only
B. A second broadcast domain
C. Survival of a single break by wrapping traffic the other way
D. Automatic NAT

<details>
<summary>Show answer</summary>

**Correct answer: C.** A dual ring can wrap traffic in the opposite direction when one link breaks. It is a resilience feature, not a bandwidth guarantee.

</details>

#### MCQ 25. A tree topology is best described as:

A. Every node connected to every other node
B. A hierarchy of star networks
C. A single cable shared by all nodes
D. A ring of rings

<details>
<summary>Show answer</summary>

**Correct answer: B.** A tree combines stars in a hierarchy, with access, distribution, and core layers. Upper links and the root are single points of failure.

</details>

#### MCQ 26. What is the difference between physical and logical topology?

A. Physical is the arrangement of devices and cables; logical is how traffic flows.
B. Physical is IP; logical is MAC.
C. Logical is always a star.
D. They are the same thing.

<details>
<summary>Show answer</summary>

**Correct answer: A.** Physical topology is the layout; logical topology is the traffic path through subnets, VLANs, and routes. They can differ.

</details>

#### MCQ 27. A partial mesh topology is common in WAN cores because it:

A. Eliminates all single points of failure
B. Requires no routing
C. Balances redundancy against link cost
D. Uses only wireless links

<details>
<summary>Show answer</summary>

**Correct answer: C.** A partial mesh gives redundant paths where they matter without the cost of connecting every node to every other.

</details>

#### MCQ 28. A hybrid topology is:

A. A topology with no switches
B. A star with one device
C. A ring with no nodes
D. A combination of two or more topologies

<details>
<summary>Show answer</summary>

**Correct answer: D.** Real networks often combine topologies, such as star access with a mesh core. The combination is a hybrid.

</details>

#### MCQ 29. Which is a single point of failure in a star topology?

A. Each individual cable
B. The central switch or hub
C. The DNS server
D. The default gateway only

<details>
<summary>Show answer</summary>

**Correct answer: B.** Every device depends on the central switch or hub, so its failure isolates the star. A single cable failure affects only one device.

</details>

#### MCQ 30. Which topology is largely obsolete in LANs because a backbone break can take down the segment?

A. Bus
B. Star
C. Tree
D. Partial mesh

<details>
<summary>Show answer</summary>

**Correct answer: A.** A bus depends on one backbone; a break or heavy collisions affect every attached node. Star and tree topologies replaced it in LANs.

</details>

A. Switch
B. Router

D. Hub

<details>

**Correct answer: D.** A hub repeats bits to every port, so all ports share one collision domain. It is obsolete in modern LANs.

#### MCQ 32. Which device forwards frames by MAC address?

A. Router
B. Hub
C. Switch
D. Modem

<details>
<summary>Show answer</summary>

**Correct answer: C.** A switch learns MAC addresses and forwards frames to the relevant port. A router forwards by IP address instead.

</details>

#### MCQ 33. Which device forwards packets between IP networks and acts as the default gateway?

A. Router
B. Switch
C. Hub
D. Access point

<details>
<summary>Show answer</summary>

**Correct answer: A.** A router forwards packets between networks and is the gateway hosts use for off-subnet traffic.

</details>

#### MCQ 34. Which device bridges Wi-Fi clients onto the wired LAN?

A. Router
B. Access point
C. Firewall
D. Load balancer

<details>
<summary>Show answer</summary>

**Correct answer: B.** An access point connects wireless clients to the wired network. A router may also provide Wi-Fi, but the bridging function is the access point's job.

</details>

#### MCQ 35. Which device filters traffic by rules and connection state?

A. Switch
B. Hub
C. Access point
D. Firewall

<details>
<summary>Show answer</summary>

**Correct answer: D.** A firewall applies rules and tracks connection state. A switch forwards frames, and a hub repeats bits.

</details>

#### MCQ 36. Which device distributes requests across servers and checks their health?

A. Proxy
B. Modem
C. Load balancer
D. Hub

<details>
<summary>Show answer</summary>

**Correct answer: C.** A load balancer spreads traffic across backends and removes unhealthy nodes. A proxy forwards on behalf of clients but does not necessarily balance.

</details>

#### MCQ 37. Which device forwards requests on behalf of clients and can cache responses?

A. Proxy
B. Router
C. Switch
D. Access point

<details>
<summary>Show answer</summary>

**Correct answer: A.** A proxy sits in the request path for clients and can cache or filter. A router forwards packets between networks.

</details>

#### MCQ 38. Which device converts the provider's signal to Ethernet at a home or small office?

A. Switch
B. Modem
C. Load balancer
D. Proxy

<details>
<summary>Show answer</summary>

**Correct answer: B.** A modem converts the provider's signal into Ethernet. Switches and load balancers work inside the local network.

</details>

#### MCQ 39. A load balancer terminates TLS and sends requests to several servers. Which symptom can result?

A. DNS stops resolving.
B. All clients get the same IP.
C. Sessions or certificates may differ per backend node.
D. The default gateway disappears.

<details>
<summary>Show answer</summary>

**Correct answer: C.** When TLS terminates at the balancer, each backend may have different sessions or certificates, causing intermittent behavior. DNS and the gateway are separate concerns.

</details>

### Collision domains, broadcast domains, and VLANs

#### MCQ 40. What does a switch do to collision domains?

A. Merges all ports into one domain
B. Extends the domain to every VLAN
C. Removes the need for MAC addresses
D. Gives each port its own collision domain

<details>
<summary>Show answer</summary>

**Correct answer: D.** A switch gives each port its own collision domain, and full-duplex ports do not collide. A hub is the device that merges ports into one domain.

</details>

#### MCQ 41. What device breaks a broadcast domain?

A. Hub
B. Router
C. Switch
D. Access point

<details>
<summary>Show answer</summary>

**Correct answer: B.** A router does not forward broadcasts by default, so it breaks the broadcast domain. Switches extend it within a VLAN.

</details>

#### MCQ 42. What does a VLAN create?

A. A new physical cable
B. A larger collision domain
C. A separate broadcast domain on the same switches
D. A new default gateway automatically

<details>
<summary>Show answer</summary>

**Correct answer: C.** A VLAN is a logical partition that creates a separate broadcast domain. It does not create physical links or configure a gateway by itself.

</details>

#### MCQ 43. Two devices are in different VLANs. What do they need to communicate?

A. Routing and usually a firewall rule
B. Only a hub
C. A crossover cable
D. A DNS record

<details>
<summary>Show answer</summary>

**Correct answer: A.** Different VLANs are separate broadcast domains, so traffic must be routed and is often filtered by a firewall rule. A hub or cable cannot join them.

</details>

#### MCQ 44. A test client can reach a server by IP on the same subnet but not after the server moves to another VLAN. What is the most likely cause?

A. The client's keyboard layout
B. The server's MAC address changed
C. DNS is down
D. Routing or firewall rules between the VLANs are missing or wrong

<details>
<summary>Show answer</summary>

**Correct answer: D.** Moving to another VLAN changes the path from local switching to routing and firewall policy. DNS is not involved when the client uses the IP directly.

</details>

#### MCQ 45. Which statement about broadcast domains is correct?

A. Routers forward broadcasts by default.
B. Switches forward broadcasts within a VLAN.
C. VLANs merge broadcast domains.
D. Broadcasts cross the internet unchanged.

<details>
<summary>Show answer</summary>

**Correct answer: B.** Switches flood broadcasts to every port in the same VLAN. Routers do not forward broadcasts, and VLANs separate rather than merge domains.

</details>

## Part 3 — Addressing and Subnetting (40 questions)

### IPv4 basics

#### MCQ 46. How many bits are in an IPv4 address?

A. 16
B. 32
C. 64
D. 128

<details>
<summary>Show answer</summary>

**Correct answer: B.** IPv4 uses 32 bits, written as four octets. IPv6 uses 128 bits.

</details>

#### MCQ 47. How many octets does an IPv4 address have?

A. 2
B. 3
C. 4
D. 8

<details>
<summary>Show answer</summary>

**Correct answer: C.** Four octets of 8 bits each make 32 bits, such as 192.168.1.10.

</details>

#### MCQ 48. What is the range of each IPv4 octet?

A. 0–255
B. 1–254
C. 0–127
D. 1–256

<details>
<summary>Show answer</summary>

**Correct answer: A.** An octet is 8 bits, so it ranges from 0 to 255. Values above 255 are invalid in an IPv4 address.

</details>

#### MCQ 49. Which address is a valid unicast IPv4 host address?

A. 224.0.0.1
B. 255.255.255.255
C. 192.168.1.0/24
D. 192.168.1.10

<details>
<summary>Show answer</summary>

**Correct answer: D.** 192.168.1.10 is a normal host address. 224.0.0.1 is multicast, 255.255.255.255 is broadcast, and .0 is the network address in a /24.

</details>

#### MCQ 50. What does the subnet mask identify?

A. The DNS server
B. Which bits are network and which are host
C. The default gateway's MAC address
D. The physical cable

<details>
<summary>Show answer</summary>

**Correct answer: B.** The mask's 1 bits mark the network portion and its 0 bits mark the host portion. DNS, MAC addresses, and cabling are separate concerns.

</details>

#### MCQ 51. What is the network address of a subnet?

A. The address with all host bits set to 0
B. The address with all host bits set to 1
C. The first usable host
D. The gateway address

<details>
<summary>Show answer</summary>

**Correct answer: A.** The network address has every host bit at 0. The broadcast address has every host bit at 1.

</details>

#### MCQ 52. What is the broadcast address of a subnet?

A. The first address in the range
B. The gateway address
C. The address with all host bits set to 1
D. The DNS server address

<details>
<summary>Show answer</summary>

**Correct answer: C.** All host bits set to 1 is the broadcast address for that subnet. It reaches every host in the subnet and cannot be assigned to one host.

</details>

#### MCQ 53. Which address cannot be assigned to a normal host?

A. 10.0.0.5
B. 172.16.1.20
C. 192.168.1.1
D. 192.168.1.255 in a /24

<details>
<summary>Show answer</summary>

**Correct answer: D.** In a /24, .255 is the broadcast address. The other addresses are ordinary usable addresses.

</details>

#### MCQ 57. What is the purpose of a default gateway?

B. To assign IP addresses
C. To forward traffic to other subnets
D. To encrypt traffic

<details>
<summary>Show answer</summary>

**Correct answer: C.** The gateway forwards traffic whose destination is outside the local subnet. DNS resolves names and DHCP assigns addresses.

</details>

#### MCQ 58. Which address is link-local?

A. 10.1.1.1
B. 169.254.1.1
C. 192.168.1.1
D. 172.16.1.1

</details>
